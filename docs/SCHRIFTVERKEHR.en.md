# Guide: Letters, Mail Merges, Minutes, Templates and Document Archive

> Part of the [Handbook](HANDBUCH.en.md) – see chapter 11 there for the full picture including corporate design.

## Club logo
*Administration › Club / Settings / Logo* → **Club logo** field (PNG or JPG). The logo then appears top right on
all PDF documents (letters, mail merges, invoices, reminders, loan slips, donation receipts), in the Word export,
and next to the club name in the header. To change it: upload a new file. To remove it: tick "Delete". The club
has its own logo. The **Signature 1/2** fields fill the `{unterschrift_1}` / `{unterschrift_2}` placeholders.

## Templates (freely editable)
*Correspondence › Templates*. Supplied out of the box: invitation to general meeting / board meeting / event,
minutes of general meeting / board meeting, member newsletter, membership fee information, anniversary
congratulations, OpenSlides login credentials, general letter. Every template can be edited, copied (under a
new name), or created from scratch.
* **Type** determines what the template is offered for; the **default template** is used when creating an
  invitation/minutes for an event.
* Separate paragraphs with a **blank line**; simple line breaks are preserved.
* Placeholders such as `{briefanrede}`, `{name}`, `{veranstaltung_datum}`, `{tagesordnung}` – see the
  **placeholder help**.
* "Reload default templates" adds any missing standard templates without overwriting ones you've changed.
* Please check invitation deadlines and formal requirements against your **bylaws** – the sample texts are
  only suggestions.

## Individual documents (invitation, minutes, letter)
* From an **event**: "Create invitation" / "Create minutes" buttons – the draft is built from the default
  template using the event's data and agenda.
* Or freely: *Correspondence › Documents › New*, choose a template (the text is copied in and can then be
  edited freely).
* On the detail page: **view PDF**, **Word (.docx)** for further editing, **save as PDF to the archive**.
* Placeholders that could not be replaced are shown as a notice.

## Mail merges
1. *Correspondence › Mail merges › New* (or, from an event, "Invitation to members (mail merge)").
2. Choose a template, adjust the text, set the **recipient group** (status, membership type, department,
   role, email address required or not).
3. Detail page: check the recipient count, view the **preview** (first recipient).
4. **Generate all letters & save to archive** – one PDF, one letter per member (each with logo and personal
   salutation) → ready to print.
5. **Send by email** – text in the email body, letter attached as PDF, to every recipient with an email
   address (runs in the background). The result (number sent/failed/without an address) appears on the
   detail page.

## Document archive
*Correspondence › Archive* and *Archive folders*. The folder structure is created when the club is set up
(minutes, invitations, mail merges, bylaws & contracts, receipts, miscellaneous) and automatically split by
**year**.
* PDFs generated by the system land automatically in the matching folder (category/year).
* **Uploading external documents:** the archive is not limited to documents generated by this software – via
  *Correspondence › Archive › "New"* you can upload any externally created file (PDF, Word, scanned bylaws/
  minutes, photos …) and give it a title, category, folder, date, description and tags; optionally link it to
  an event.
* **Versioning:** the same title in the same folder → a new version; earlier versions are kept and remain
  visible.
* Access to files only works through the application (login + club membership + "Archive" permission).
* Permissions: "Archive" and "Correspondence" modules – granted via the permission matrix or tags (the
  Secretary has editing rights under the data protection bylaws, see Handbook chapter 2).

## Recommended workflow for a general meeting
1. Create an event (type "Meeting"), record the agenda (or use "standard agenda").
2. "Create invitation" → review → PDF; "Invitation to members (mail merge)" → print/email. Mind the
   deadlines in your bylaws!
3. Optional online/hybrid: "Create in OpenSlides", sync accounts, distribute login credentials via mail merge.
4. After the meeting: "Create minutes", fill them in (Word export possible), file the signed minutes as a
   scan in the archive.
5. Follow up on resolutions/honours (honours, fee changes).
